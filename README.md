# Moody Love Eid 💕

A romantic multi-page website in rose gold & dark red, synced via Supabase.

## Pages

| File | Purpose |
|------|---------|
| `secret.html` | Password gate (start here) |
| `love-me.html` | "Do you love me?" |
| `memories.html` | Counter, music, photo galleries |
| `ring.html` | Ring photo & message |
| `message.html` | Love letter |

**Password:** `Moodylovesrumi` (case sensitive)

## Setup

1. Open [Supabase](https://supabase.com/dashboard) for project `xsiralxleayvmadzxkwg`.
2. Run `supabase-setup.sql` in the SQL Editor.
3. Create a **public** storage bucket named `moody-love`.
4. Serve the folder locally (e.g. VS Code Live Server) or deploy to Netlify/Vercel/GitHub Pages.
5. Open `secret.html` in the browser.

## Local preview

```bash
npx --yes serve .
```

Then visit `http://localhost:3000/secret.html`.
